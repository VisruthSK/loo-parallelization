## Questions for Meeting

### How to use `mori` properly as a package owner? (with `mirai`)

I haven't gone through GH to find pakcage swhich are using `mirai` for paralellization and also use `mori`, but the main question I am have is how to use `mori` opportunistically to avoid copying shared objects to all workers in `mirai`. If all deamons are remote then `mri` cannot be used, but if there are mixed remote and local daemons then it should technically be possible to share the common objects to just the local deamons and copy them over to the remote. The main blocker here is finding a solution which is clean and automatic, instead of relying on on the users to specify where where their compute resides.
